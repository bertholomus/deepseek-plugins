## Findings (most severe first: blocker, major, minor, nit; each with where, what, and the fix)

1. **Minor: Back from a turn opened on the tool card shows another search.** Where: `lib/client.js`, `ToolResults` (*Open* calls `openResult(r, { query: view.query, page: true })`, which leaves the page's own search as it was) and `RecallMark` (*Back to the results* calls `views.openPage()`). What: in "Find the earlier build flag", *Open* on the card marked turn 2 "for “walrus build flag”" (pic 10); *Back to the results* then showed the page's earlier search, "walrus OR zeppelin OR capybara OR quokka" (pic 11). The README says Back "returns to the same search". By the code, a transcript or another DSH's result opened from a card shows its reading view over the page's old search in the same way. Fix: when *Open* comes from a tool card, set the page's search to the card's query and filters first (as *Search this in Recall* does), so Back lands on the results the agent saw; add a check to the e2e's tool-card step.
2. **Minor: rows on the page keep a turn's old state until you search again.** Where: `lib/client.js`, the page's refresh in `createFinder` and its use (about lines 1992 to 2022): with nothing typed the list is searched again only when the number of turns grows, and with words typed only when you search (its "Recall has read more since this search" note, too, appears only when the number of turns grows); a turn's end changes neither. What: "Find the earlier build flag" completed at 8:14 PM (DSH's log) and still read "still running" on the page at 8:17 (pic 11); the two Ibis turns I stopped stayed "still running" for 30 s without Session Watch and 20 s with it, until I pressed Enter. The README's *still running* is "only while DSH says its session runs"; a person who searched while a turn ran sees it running for as long as the list stays up. Fix: when the index records the end of a turn that is shown, refresh the shown results' states (or search again quietly, keeping scroll position and focus); add an e2e check that stops a shown turn.
3. **Minor: words split between a session's title and its turns count every turn that says one of them, and can open the wrong turn.** Where: `lib/engine.js`, `ownHit` (`r.own < 0`: `own` is bm25 with the title's weight at 0, so it is below 0 when the row's own text says any one of the words), and the count and grouping that use it. What: "walrus session" gives "57 matching turns in 2 sessions and files"; the long session opens at turn 56, which says "session" but not walrus, with "55 other turns here match", and turn 2, its only turn that says walrus, is one of those 55 (pic 37). "walrus test" gives 55 matching turns in a session where no turn says both words, opening at turn 56 with "54 other turns here match". The README says "A turn that does not say them is never listed, even when its session's title does" and "The count is of turns that say the words". Fix: count a row as saying the words only when its own text matches the whole query (an FTS5 column filter on the request, reply and tool columns); list the rows that need the title after those, opening at the turn whose own text says the most of the words; count only the first kind; add a unit test with this case.
4. **Nits.**
   - The header and the Index card count note sections as turns ("476 turns from 19 files" with 405 note sections, pic 20); say "turns and note sections".
   - `enabled: false` written live: the header kept "Up to date" for over 30 s while searches said "Not searched: Recall is switched off in DSH's profile (enabled: false)…", and What happened has no entry for it (pic 38). The wrong-`enabled` page says "then restart DSH" (pic 16), while the switched-off page says "DSH applies it when you save the file", and `true` written live came back by itself in 3 s.
   - The 5 MB note is listed under "Files Recall could not read", though its first 4 MB are searched ("okapi", before the cut, is found; "tapir", after it, is not) (pic 20); list it as read in part.
   - A file named as a folder is tagged "cannot read" (pic 19); its sentence is right.
   - "Read 0 files in under a second; nothing in them was new." (pic 17).
   - Tool lines in snippets show full `/Users/…` paths (pic 12), where the rest of the page says `~/`.
   - A phrase that matches nothing reads `Nothing matches “"frame skip zebra"”` (two pairs of quotes).
   - A running turn opened from the page gets no mark and no way back (pic 36).
