## Behaviour
1. Click on empty card area flips the card. The star, Ready/Copy/Swap/Load chips, "Load on any set of Ascents..."
   and every other existing control keep working and do NOT flip it. Add a small visible flip/info affordance too.
2. Keyboard: the card is focusable. Enter/Space flips it. Esc or a click on the back flips it back. Use aria-pressed or
   aria-expanded and an accessible label. Focus stays on the card.
3. Only one card shows its back at a time (opening one closes the other), unless that looks wrong; you decide and log.
4. Grid layout must not jump: the back takes the front's exact size (rows are uneven heights today).

## Back of the card (what people want to know)
Use only data we really have or can fetch and cache on the host. Never invent a value; leave a field out if unknown.
- Name, author picture + badge (Official / Quant / Ours), one-line description if the model card has one.
- Source links: Hugging Face repo (from the "from org/repo" origin and our own repo), GitHub repo if the model card
  or org links one, license (with a link). Links open in the system browser, not inside DSH.
- Architecture facts: total / active parameters, MoE expert count, context length, layers, base model,
  release date. Read them from the banked config.json / README front-matter on tank, or the HF API (cache on host;
  works offline from cache).
- Our facts: format and bpw (EXL3 4bpw TensorFold, BF16 ...), size on tank, verified / manifest state, revision,
  drafter, which Ascents serve or have it, and the last benchmark tok/s from Fleet benchmarks if one exists.
- HF downloads and likes if the API gives them (cached; show the fetch age).

## Animation (the important part)
- A real 3D flip (rotateY 180deg, perspective on the grid cell), about 500-650 ms, spring-like ease with a small
  settle; no bounce that looks cheap. Slight lift on flip (scale ~1.02, deeper shadow) then settle.
- Glass sensitive: the glass sheen / specular highlight sweeps across the card as it turns; the edge catches light at
  90deg; the back is the same frosted glass as the front (same blur, tint, border, wallpaper showing through).
- Known Chromium/Electron pitfall: backdrop-filter breaks or goes opaque inside `transform-style: preserve-3d` with
  `backface-visibility: hidden`. Prove the frosted blur survives on BOTH faces during and after the flip, in DSH Test
  with a busy wallpaper (like the Porsche one). If it cannot, use a different technique (for example animate a
  single face and swap content at 90deg) - the look matters, not the method.
- prefers-reduced-motion: crossfade instead of rotate.
- 60 fps on the Mac mini with 43 cards on screen: no layout thrash, no blur re-raster stutter. Record a trace or
  frame timing as proof.
