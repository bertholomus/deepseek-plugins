## Findings (most severe first: blocker, major, minor, nit; each with where, what, and the fix)

1. **Major. A wrong type in the profile stops Recall, and its page gives the wrong advice.** Where: `lib/index.js` Config (`z.array(z.string())`, `z.boolean()`), the page's not-running state, README "Settings". What: `transcriptFolders: ~/Projects/…/agent-logs` (no brackets; the README's own setup step has people edit this row by hand) or `tool: "yes"`: while DSH runs the edit is dropped without a word (Recall keeps the old value); at the next start Recall does not run, Plugins shows "Problem" with no reason and no settings form, and Recall's page says to switch it off and on or restart DSH, which cannot help. The README says a wrong value never stops Recall from starting. Fix: let the Config accept any value for these keys and leave the check to `checkConfig`, which already has the words ("… must be a list of folders, such as ["~/notes"] (it is …)") but never sees a string; test a string list, a quoted boolean and a number with the e2e's `restartWith`.
2. **Major. A session title's words match every turn of it, and can choose the wrong turn.** Where: the index's per-turn title column (weight 4) with the recency lift. What: "heron" opens turn 3 of the heron transcript ("Log the axolotl metric too", no heron in its own text) and lists turn 1, where the worker was renamed, as an "other turn"; "gyrfalcon" shows "8 other turns here match: turn 2 … turn 8" where only turns 1 and 8 say it; counts are inflated the same way. DSH titles come from the first request, so this is the common case. Fix: score a title-only hit once per session (or only as a tie-breaker), never above a turn whose own text matches, and list as "other turns" only turns with their own hit.
3. **Minor. Turns that stopped are not called stopped, and a cut turn never closed reads "still running" for ever.** Where: `lib/engine.js` `running()`, the rows, the reading view, the tool. What: after a crash or restart, a session DSH never reopens has no end mark, so its last turn shows "still running" in results, "turn 1 · still running of 1" and "This turn is still running." in the reading view, while DSH lists the session idle and its chat says "Task stopped"; a turn DSH closed as interrupted or aborted shows only "This turn has no reply text.", and the agent asked "whether it finished" got no end state. Fix: count a DSH turn as running only while DSH says its session is running (or its log moved lately, as for transcripts); keep the end's reason and say "stopped", "failed" or "cut off by a restart" in rows, reading view and tool.
4. **Minor. The tool lists the asking turn as earlier work.** Where: `lib/tool.js`. What: the agent's search for "gyrfalcon_notes.txt" returned its own question as result 2 of 2, and the tool card offers Open on it. Fix: leave out the calling session's current turn.
5. **Minor. Focus is lost after Back once the reading view moved.** Where: `lib/client.js` `backToList`. What: open a transcript result, Turn before, Back to the results: focus lands on the page body (it looks for a row for the turn now shown). Fix: remember the row that opened the reading view and focus it.
6. **Minor. The index keeps its size after a big folder leaves.** Where: the index thread's take-out and rebuild. What: after the 10,002-file folder was taken out, and again after Rebuild the index, `index.sqlite` stayed 290 MB for 289 turns; the card reads "289 turns from 43 files · 280 MB on this computer". Fix: `VACUUM` (or incremental vacuum) after a large take-out and on Rebuild.
7. **Minor. Transcripts without times are dated 1970.** Where: the transcript reader. What: a transcript of plain role lines written today has no time; "Past week" leaves it out and Newest puts it last. Fix: fall back to the file's modified time.
8. **Minor. Words and names.** "still running of 1"; "1 other section of this note match:"; "… sections of this note match" with nothing typed; "Clear the filters" twice in one state; "it is a file, not a folder. Check that DSH may read it." (lower case, and the advice is about permission); "Its turns stay as last read" for a file never read; "Read 1 file in 0 seconds: 0 turns and note sections indexed."; "Reading what changed…" for a new folder, with no total ("of 10,002 files"); full `/Users/…` paths in "Inside …" and "Stopped searching …" where the rest says `~/`; "To remove it instead, switch it off in Plugins" (that does not remove it); raw Markdown in snippets ("[gyrfalcon_notes.txt](gyrfalcon_notes.txt)", "```bash"); the folder menu cuts paths at the end; buttons named only "Read here", "turn 2", "section 2" or "Open". Fix: each as written, cut paths in the middle, and name buttons with their result ("Read “Long gyrfalcon session”, turn 1 here").
9. **Nit.** With Session Watch off, the window logs a 404 for its `wait` endpoint every few seconds (backing off to 10 s); at 420 px the kind switcher is 7 px wider than its box; newest-first paging stops at the candidate cap (no results at offset 1,000 on the 10k index), though the page never asks for it.
