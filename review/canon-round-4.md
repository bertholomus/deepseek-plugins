## Findings (most severe first: blocker, major, minor, nit; each with where, what, and the fix)

1. **Major: the quote is too thin to answer what was asked.** Where: `bestPassage` in `lib/vault.js`, which adds the next paragraph only when it sits under the same heading. What: rm1's block quoted one sentence of Gateway ports (384 of 2,000 characters). It left out the note's "Changing a port" section, which answers the second half of the question. The try-out shows the same block, so this is Canon's own output whatever the model. The model that answered (DeepSeek-V4.1-Flash-1017, served in GLM's place) then listed the folders above its workspace, found the vault copy, and read the note and a draft from `Drafts/` (Canon promises never to give a turn a draft). rm7's Routing rules quote ends at "Today:" without the list it introduces. If the vault were under `~/Obsidian`, the same search would walk the person's home folder. Fix: when the note's share of the budget allows, quote the whole note (every fixture note but the home note has under 600 characters of body, and a one-note block has room for about 1,700), or else the best paragraph of each section that shares the prompt's words; never end a quote on a line ending in ":" without what follows; test both, and a two-part question.
2. **Major: a promoted decision and the note it changes arrive side by side, with nothing to say which is current.** Where: the block's citation line in `lib/recall.js`, and `promote` in `lib/drafts.js`. What: after I promoted the 80 ms decision, both later sessions got it in one block beside Client settings (50 ms). That is Canon's output, chosen before any model answered. The block carries no status, date or kind, and the promoted note's own body still says "captured here as a draft for review before it is promoted". So a reader of the block alone cannot tell which note is current. Both turns' model (DeepSeek-V4.1-Flash-1017, served in GLM's place) went to the disk to read the frontmatter. One listed `~/canon ~/Projects/*canon* ~/.*canon*`, and I stopped that turn. Fix: give each cited note its kind and date in the block ("decision, promoted 2026-10-26"; `date`, `updated` or `created` otherwise) and put the newer of two conflicting notes first; on the drafts card, show the active notes a draft's subject shares and let the person mark one superseded when promoting (a person's action, logged).
3. **Major (known and documented): questions worded unlike the notes still miss.** Where: the fit rules in `lib/search.js` and `lib/text.js`. What: my stress set misses two floors (73.3% first, 86.7% in the block), as do the builder's guard (75.0%, 79.2%) and probes (74.0%, 79.2%); "how do I get a new version of this live?" in harbor-gateway gets Routing rules, "who's responsible for this frontend?" gets the local-run note, "How do I ship a new build of this service to production?" gets nothing. Fix: a small, documented list of operational synonyms read like aliases (ship, release, push live, roll out and deploy; owner, responsible, looks after; dump and backup), then one measurement on a fresh hold-out of paraphrased questions.
4. **Minor: a decision that says how to save it is read as a coding request.** Where: `isCodingRequest` and the decision-statement rule in `lib/text.js`. What: rm2's message (a decision, then "Save that as a draft decision note with the canon_capture tool … Do not edit any files yourself.") got no note: Client settings scored 31% where a third is needed (the try-out says so too). So the decision was saved as a draft by an agent that never saw the note it changes. Fix: count a sentence that asks to save, record or capture (tool names included) as part of a decision statement, and add such messages to the dev set.
5. **Minor: a draft cannot be read in full or discarded on the page.** Where: the Drafts card in `lib/client.js`. What: a person decides on Promote from a two-line excerpt (the saved draft is cut at "Status: agreed in…"), and a draft nobody wants stays until someone deletes it in Obsidian. Fix: a disclosure with the whole body (and a link that opens the note in Obsidian), and a person-only *Discard* that moves the draft to the vault's `.trash`, logged.
6. **Nits.** The README's draft example quotes `by: "canon_capture"`; the file has `by: canon_capture`. The README carries about 100 lines of measurement history (rounds, commit ids, OPEN-QUESTIONS numbers) between what a turn gets and the card; move it to a separate file. What happened gives no new value while another setting is still wrong ("Settings changed: “Notes a turn, at most”; Canon waits …"). *Save it as 3* sits under the "Also wrong" list, away from the setting it fixes. Neither I nor the e2e checked the page with Wallpaper on.
