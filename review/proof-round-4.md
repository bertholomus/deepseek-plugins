What: live, two of my nine quiet real-model turns, both look-only explanations, got "Proof · Nothing in this turn shows this": "pct is documented as a percentage (10 meaning 10%)" (read as a done claim: "Nothing in this turn changed a file or ran a change.") and "With a literal "10", it returns `100 - 100*10 = -900`." (read as an endpoint claim: "Nothing in this turn checked it: no request to it and no status read ran."). Aimed probes of the same kind flag 4 of 12: "Retries are configured in `config/retry.yml`", "It is deployed on Fly as `acme-api` … according to `fly.toml`", "it is already fixed upstream in `b2c3d4e`" and, after `prisma migrate status` printed "Database schema is up to date!", "all 3 migrations … are applied there". The README says descriptions of how a thing is set up, what code does and what a commit once did claim nothing. The owner asks "explain" and "where does this run" all day, and a flag on a correct explanation teaches him to ignore the flags. Fix: in a turn that changed nothing, a present-tense passive or stative clause ("is documented as", "is configured in", "is deployed on", "is already fixed in <commit>", "it returns <value>" about code) claims nothing; a status read (`prisma migrate status`, `kubectl get`, `helm status`, `git log`) shows a stative claim about what it printed; add my two live replies and the twelve description probes (or their shapes) to the dev corpus.
2. **Major (visible): the card and the ledger print "undefined" into the quoted claim.** Where: `lib/claims.js` 186-189: `hold()` turns " - " inside code, quotes or brackets into " \u0006 ", and `unhold()` looks up the key whose value is the bare "\u0006", finds none and inserts `undefined`. What: "Changed `x - 1` to `x + 1`" shows as «Changed x undefined 1 to x + 1 in src/a.js.», "It returns `a - b` now." as «It returns a undefined b now.», live «With a literal "10", it returns 100 undefined 100*10 = -900.» (`08-flag-undefined-in-quote-light.png`). The card and the ledger row show this clause (`lib/client.js` 1372 and 1607); the session row and the exports use the whole sentence, so the same claim reads two ways. Verdicts are unaffected. Fix: map "\u0006" back to "-" (or hold " - " as one symbol), and add a unit test and an e2e check on a card whose clause holds " - " in code.
3. **Minor: four claim shapes are not read, and one is misjudged.** Where: `lib/claims.js` (claim verbs, the negation rule) and `lib/evidence.js` (rollouts). What: with no edit at all, "Added a `--dry-run` flag to `bin/cli.js` (it prints what would be synced and changes nothing) and documented it …" claims nothing: the "changes nothing" inside the brackets silences the sentence (without it, it is flagged).
